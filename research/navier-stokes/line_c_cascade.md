Status legend (one tag per claim): **PROVED-HERE** (complete proof written out, every step checkable), **KNOWN** (cited, not reproved), **COMPUTED** (script plus printed output below), **CONJECTURE**, **FAILED** (attempted, with the exact breaking step). ## Goal

Tao's 2016 program (no-go item 2.2) has two halves. The first is a *mechanism*: a cascade in which a quadratic, energy-conserving, scale-invariant nonlinearity moves an order-one fraction of the energy from scale `2^n` to scale `2^(n+1)` in a time that shrinks geometrically fast enough to beat viscous damping, so that infinitely many transfers happen before a finite time `T*`. The second is a *carrier*: a bilinear operator `B~` that supports the mechanism while retaining every property of the true Euler nonlinearity `B(u,v) = -P((u.grad)v)` that the known regularity theory uses. This line does the first half concretely on ODE (dyadic / shell) models, measures where it stops, and then states precisely which structural property of `B` blocks the second half for the true equation. The intended output is not "a blowup"; it is a quantitative location of the boundary between the cascade regimes, and a list of the exact properties an engineered nonlinearity must break.

Line A of this project asked whether a coercive Lyapunov functional could rule out blowup and found that none of the natural candidates works; this line asks the complementary question, whether the cascade that would produce blowup can be built. In the one-mode-per-scale class it does not beat the true dissipation in any run performed here (C7, C8); this line measures by how much it falls short and identifies the structural reason. The literature reports that the corresponding statement about the untruncated model is a theorem — Barbato-Morandin-Romito 2011, for positive solutions of the viscous dyadic model — but the exponent range and solution class of that theorem were not read anywhere in this project (`00_problem.md` section 0), and under this file's own inferred `alpha = 2 s / 5` dictionary the Cheskidov thresholds do not cover `s = 1` at all. So the global-regularity statement for the untruncated model at `s = 1` is carried here as **CONJECTURE** supported by COMPUTED evidence on truncated systems, not as KNOWN; the citation dependence is spelled out at the point of use in C7.

## Setting and notation

The dyadic (shell) model studied here is, for `n = 0, 1, 2, ...` with the conventions `a_{-1} = 0` and `a_N = 0` at a truncation to `N` shells,

```text
da_n/dt = -nu * 2^(2 s n) * a_n  +  lam^n * a_{n-1}^2  -  lam^(n+1) * a_n * a_{n+1},     lam = 2^(5/2).
```

`a_n(t)` is the amplitude of the `n`-th dyadic shell in an `L^2`-normalized basis, so that `E = sum_n a_n^2` is the energy analogue, `H^1 = sum_n 4^n a_n^2` is the enstrophy analogue, `k_n = 2^n` is the physical wavenumber, and `s = 1` (dissipation `4^n = k_n^2`) is the true Navier-Stokes Laplacian. The nonlinear coefficient base `lam = 2^(5/2)` is not a free choice: C2 below shows it is the unique base for which the model has the exact Navier-Stokes scaling symmetry of `00_problem.md` section 1.6 together with the dissipation `4^n`.

Two normalizations appear in the literature and they must be kept apart. Writing the model in "flux units", with `K_n := lam^n` as the coefficient of the nonlinearity and the dissipation as `nu * K_n^(2 alpha)`, the exponent `alpha` is the one used by Katz-Pavlovic and Cheskidov; writing it in "physical units", with dissipation `nu * 2^(2 s n) = nu * k_n^(2 s)`, the exponent `s` is the one used here and in the Lions/hyperdissipation literature (`00_problem.md` item 2.10). The dictionary is `2 s n = 2 alpha * (5/2) n`, i.e. `alpha = 2 s / 5`:

| quantity                            | this file (`s`, dissipation `2^(2 s n)`) | flux units (`alpha`, dissipation `lam^(2 alpha n)`) | ratio to critical |
| ----------------------------------- | ---------------------------------------- | --------------------------------------------------- | ----------------- |
| Cheskidov's stated blowup boundary `alpha < 1/3`, translated by the inferred dictionary | `s = 5/6 ~ 0.8333`                       | `alpha = 1/3`                                       | `2/3`             |
| true 3D Navier-Stokes dissipation   | `s = 1`                                  | `alpha = 2/5`                                       | `4/5`             |
| energy criticality = Lions exponent | `s = 5/4`                                | `alpha = 1/2`                                       | `1`               |

The identification of Cheskidov's `alpha` with `2 s / 5` is **inferred**, not read off the paper: it is forced by two independent consistency checks, namely that his global-regularity threshold `alpha >= 1/2` coincides with the energy-criticality exponent computed in C2 below, and that his remark "`alpha = 1/3` enjoys the same estimates as 4D Navier-Stokes" matches the ratio `alpha / alpha_crit = 2/3`, which is exactly the ratio `1 / ((d+2)/4)` at `d = 4`. Note the last column: the dyadic model with the true `4^n` dissipation sits at `4/5` of critical, exactly where true 3D Navier-Stokes sits, which is the sense in which the model is scale-faithful.

Because that dictionary is inferred and because no paper was read (`00_problem.md` section 0), every use below of a Cheskidov or Barbato-Morandin-Romito threshold is flagged where it is used, and **no claim in this file rests on one**: the thresholds are quoted only as pointers for a reader with library access, and every statement of this file that could be confused with one of theirs carries the status of its weakest input.

Two profiles will be compared throughout. The **scale-invariant profile** `a_n = c 2^(-n/2)` is the fixed point of the model's scaling map (C2). The **constant-flux (K41) profile** `a_n = c 2^(-5n/6)` is the one that makes the shell-to-shell energy flux `lam^(n+1) a_n^2 a_{n+1}` independent of `n` (C5). The second is strictly steeper than the first, and C10 argues — as a scaling heuristic (CONJECTURE), around a PROVED-HERE power-law core — that this one inequality is the reason the model does not blow up at `s = 1`.

## Results

### C1. Exact energy conservation (inviscid) and the energy identity — **PROVED-HERE**, confirmed **COMPUTED**

Proof. With `a_{-1} = 0` and `a_N = 0`, and all sums over `0 <= n <= N-1`,

```text
(1/2) d/dt sum_n a_n^2 = sum_n a_n (lam^n a_{n-1}^2 - lam^(n+1) a_n a_{n+1})
                       = sum_n lam^n a_{n-1}^2 a_n  -  sum_n lam^(n+1) a_n^2 a_{n+1}.
```

Re-index the first sum by `m = n-1`: it becomes `sum_{m=-1}^{N-2} lam^(m+1) a_m^2 a_{m+1}`, whose `m = -1` term vanishes because `a_{-1} = 0`, and whose remaining terms are exactly the second sum (its `m = N-1` term vanishes because `a_N = 0`). The two sums cancel term by term. With the dissipation restored, `(1/2) d/dt sum_n a_n^2 = -nu sum_n 2^(2 s n) a_n^2 <= 0`. QED. Script part 1a verifies the inviscid telescoping symbolically for `N = 8` with `lam` free; part 1b verifies the viscous identity with `lam`, `nu` and `s` all free. (The earlier version of this sentence described part 1b as using the dissipation `lam^(2n)`, i.e. the special case `s = 5/2`; the script now uses `2^(2 s n)` with `s` symbolic. The dissipation is diagonal, so it plays no part in the telescoping either way.)

This is the property that makes the model a legitimate carrier of Tao's mechanism: it has the exact energy identity of `00_problem.md` item 2.2, so no argument that uses only the energy identity can distinguish it from Navier-Stokes.

### C2. `lam = 2^(5/2)` is the unique base with the Navier-Stokes scaling; the scale-invariant profile — **PROVED-HERE**, confirmed **COMPUTED**

Proposition. Fix the dissipation `2^(2 s n)` and work on the **bi-infinite lattice `n in Z`** — equivalently, at interior shells `n >= 1` of the half-lattice; the boundary shell `n = 0` is a genuine exception and is treated immediately below. Define `b_n(t) := mu a_{n+1}(sig t)`. Then `b` solves the model with the same `nu` and `s` whenever `a` does, if and only if `sig * 2^(2 s) = 1` and `sig * lam / mu = 1`; i.e. `sig = 2^(-2 s)` and `mu = lam * 2^(-2 s)`.

Proof. Differentiate: `db_n/dt = mu sig (da_{n+1}/dt)(sig t)`. Substituting the equation at shell `n+1` and rewriting `a_{n+1} = b_n/mu`, `a_n = b_{n-1}/mu`, `a_{n+2} = b_{n+1}/mu` gives `db_n/dt = -nu sig 2^(2s) 2^(2 s n) b_n + (sig lam / mu) lam^n b_{n-1}^2 - (sig lam / mu) lam^(n+1) b_n b_{n+1}`, and matching coefficients with the model at shell `n` gives the two stated conditions. QED (script part 1c: residual is `0` after substitution).

Boundary shell (correction forced by the round-1 referee report). On the half-lattice fixed in "Setting and notation", with `a_{-1} = 0`, the Proposition is **false at `n = 0`** without the hypothesis just added: the model at shell `0` has no inflow term, but `db_0/dt = mu sig (da_1/dt)(sig t)` contains `mu sig lam a_0(sig t)^2 = mu^2 a_0(sig t)^2` (using `sig lam / mu = 1`), so the residual at the boundary shell is exactly `mu^2 a_0^2` — nonzero for every solution started from this file's own initial condition `a_0 = 1`. Script part 1c now prints both residuals: `0` at the interior shell `n = 3`, and `2^(5 - 4 s) A0(sig t)^2 = mu^2 a_0^2` at `n = 0`. The earlier version of this Proposition omitted the hypothesis and part 1c checked only an interior shell. Nothing downstream changes, because every later use of the map is asymptotic in `n`.

Corollary (uniqueness of `lam`). At `s = 1` the first condition forces `sig = 1/4`, which is the parabolic time scaling `t -> t/4` of `u_lam0(x,t) = lam0 u(lam0 x, lam0^2 t)` at `lam0 = 2`. The same map multiplies each shell amplitude by `lam0^(1 - 3/2) = 2^(-1/2)` (because `||u_lam0||_{L^2} = lam0^(-1/2) ||u||_{L^2}` in `d = 3`, `00_problem.md` 1.6), so its inverse — which is the map `b` above, carrying the content of shell `n+1` to shell `n`, i.e. towards coarser scales — must have `mu = 2^(1/2)`. Then `mu = lam/4 = 2^(1/2)` forces `lam = 2^(5/2)`. QED.

Corollary (scale-invariant profile). `a_n = c 2^(-n/2)` is the unique (up to `c`) profile fixed by the map `a -> b` at `s = 1`, since `2^(1/2) c 2^(-(n+1)/2) = c 2^(-n/2)`. It is **not** a stationary solution: substituting it into the nonlinearity gives residual `-2 c^2 2^(3n/2)` (script part 1e, exact). Under this map, on the bi-infinite lattice, `E -> 2E` and `H^1 -> H^1/2`; on the half-lattice the exact identities are `E(b) = 2(E(a) - a_0^2)` and `H^1(b) = (H^1(a) - a_0^2)/2`, immediate from `b_n = mu a_{n+1}` with `mu^2 = 2` at `s = 1`. Either way this reproduces the supercriticality of the energy and the subcriticality of the enstrophy of `00_problem.md` 1.6.

### C3. The `(nu, amplitude)` collapse — **PROVED-HERE**, confirmed **COMPUTED**

Proposition. If `a` solves the model with viscosity `nu` then `b_n(t) := mu a_n(mu t)` solves it with viscosity `mu nu`, for every `mu > 0`.

Proof. `db_n/dt = mu^2 (da_n/dt)(mu t) = mu^2 [-nu 2^(2 s n) a_n + lam^n a_{n-1}^2 - lam^(n+1) a_n a_{n+1}](mu t)`. The nonlinearity is exactly quadratic, so it equals `-(mu nu) 2^(2 s n) b_n + lam^n b_{n-1}^2 - lam^(n+1) b_n b_{n+1}`. QED.

Consequences used below: only the ratio `amplitude / nu` matters, so the mandatory `(nu, amplitude)` table is one-dimensional; `max H^1` scales by `mu^2` and the stall shell `n_d` (C8) is unchanged; and "blowup for large data at fixed `nu`" and "blowup for fixed data at small `nu`" are the same statement. Verified numerically in part 3 at `mu = 3` over three decades of `nu`.

### C4. The exact self-similar blowup of the inviscid model has infinite energy — **PROVED-HERE**, confirmed **COMPUTED**

Proposition. On the bi-infinite lattice `n in Z`, `a_n(t) = lam^(-n) / ((lam^2 - 1)(T - t))` solves the inviscid model exactly, for every `T`.

Proof. Write `c = 1/(lam^2-1)`. Left side: `c lam^(-n) (T-t)^(-2)`. Right side: `lam^n c^2 lam^(-2(n-1)) (T-t)^(-2) - lam^(n+1) c^2 lam^(-n) lam^(-(n+1)) (T-t)^(-2) = c^2 (T-t)^(-2) (lam^(2-n) - lam^(-n)) = c^2 (lam^2 - 1) lam^(-n) (T-t)^(-2)`. The two agree iff `c = c^2 (lam^2-1)`, which is the definition of `c`. QED (script part 1g: residual `0`).

Its energy `sum_{n in Z} a_n^2` diverges geometrically as `n -> -infinity`, and it violates the boundary condition `a_{-1} = 0` of the half-lattice model, so it is not a solution of the model actually integrated here. Reading (not a correspondence, and weaker than the earlier version of this sentence claimed): the exactly self-similar blowup of this model exists but is not in the finite-energy class, so a finite-energy blowup of the model must be a *front* rather than an exact self-similar profile. That is the same shape of conclusion as no-go item 2.3 (Necas-Ruzicka-Sverak, Tsai), but it is not an instance of it: their exclusion is by the behavior of the profile at small scales and in `L^3`, while the divergence here is at the *large* scales `n -> -infinity`, and the model has neither a velocity field nor an `L^3` norm. The algebra above is PROVED-HERE; this paragraph is a reading. The profile is also the far precursor tail seen numerically in C6 (measured slope near `-5/2 = log2(lam^(-1))`).

### C5. The constant-flux (K41) profile is an exact stationary solution and is steeper than scale-invariant — **PROVED-HERE**, confirmed **COMPUTED**

Define the shell-to-shell flux `Pi_n := lam^(n+1) a_n^2 a_{n+1}`, so that the shell energy budget reads `(1/2) d/dt a_n^2 = Pi_{n-1} - Pi_n - nu 2^(2 s n) a_n^2` (immediate from the equation; it is the term-by-term version of C1).

Proposition. `a_n = c 2^(-5n/6)` makes `Pi_n = 2^(5/3) c^3` independent of `n`, and on the bi-infinite lattice it is an exact stationary solution of the inviscid model.

Proof. `Pi_n = 2^(5(n+1)/2) c^3 2^(-5n/3) 2^(-5(n+1)/6) = c^3 2^(5n/2 - 5n/3 - 5n/6) 2^(5/2 - 5/6) = c^3 2^(5/3)`, since `5/2 - 5/3 - 5/6 = 0`. Stationarity is then `Pi_{n-1} - Pi_n = 0`, which holds for all `n in Z`; on the half-lattice it fails only at `n = 0`, where `Pi_{-1} = 0` and energy must be injected. QED (script part 1f, exact).

The comparison that drives everything below: `2^(-5n/6)` decays strictly faster than the scale-invariant `2^(-n/2)` of C2, since `5/6 > 1/2`.

Status of the conclusion, and the citation dependence, stated at the point of use (`00_problem.md` section 0). What is established here is **COMPUTED and about truncated systems**: in every `(nu, A, N)` combination above, with `s = 1`, the excitation stalls at an interior shell and the energy decays by twenty to forty orders of magnitude. The stronger statement — "the dyadic model with the true Navier-Stokes dissipation is globally regular" — is a statement about the untruncated system, and this line does **not** prove it and cannot get it from these runs (see C9). The earlier version of this section was headed "reproduces a KNOWN theorem" and rested that tag on two citations. Neither can carry it:

- Barbato-Morandin-Romito 2011 prove well-posedness of positive solutions of the viscous dyadic problem "in the relevant scaling range which corresponds to Navier-Stokes" [checked via WebSearch: title, venue Nonlinearity 24 (2011) 3083-3097, and this phrase from an abstract snippet]. **The precise interval of exponents, the definition of the solution class, and the coefficient normalization are all unverified**, since the paper was not read. ### C10. Which cascades beat dissipation `2^(2 s n)`: a power-law comparison lemma — **PROVED-HERE** — and the regime dichotomy built on it — **CONJECTURE**

The round-1 referee report was right that the version of this section tagged PROVED-HERE was scaling heuristics: it assumed the regime it characterized, used undefined `>>` and `~`, and its "Fact 1" was not a theorem. The section is therefore split. What is arithmetic is isolated as a lemma and keeps PROVED-HERE; the dichotomy that applies it to "the cascade" is **CONJECTURE**, and everything downstream that says "by C10" inherits that status — including the `5/6` and `5/4` thresholds, the `(d+2)/4` dimension corollary, the prediction behind the C8 stall law, and both breakpoints.

**Lemma (power-law comparison) — PROVED-HERE.** Let `lam = 2^L` with `L > 0`, let `nu > 0`, `s > 0`, `c > 0`, and let `A(n) = c 2^(-b n)`. Then, exactly,

```text
(i)   sum_{n>=0} 1/(lam^n A(n))  =  (1/c) sum_{n>=0} 2^((b - L) n)        converges  iff  b < L,
(ii)  lam^n A(n) / (nu 2^(2 s n))  =  (c/nu) 2^((L - b - 2 s) n)          -> +infinity  iff  b < L - 2 s,
                                                                          -> 0          iff  b > L - 2 s.
```

Proof. Both displayed identities are immediate substitutions, and each right-hand side is a geometric series (resp. sequence) with ratio `2^(b-L)` (resp. `2^(L-b-2s)`); a geometric series converges iff its ratio is `< 1` and a geometric sequence diverges iff its ratio is `> 1`. QED. (Script part 1h prints both thresholds with `L = 1 + d/2` symbolic in `d` and evaluates them on the two profiles below.)

**Corollary of the lemma — PROVED-HERE.** At `d = 3`, `L = 5/2`: for the constant-flux profile `b = 5/6` (C5), the ratio in (ii) diverges iff `s < 5/6`; for a non-decaying front `b = 0`, iff `s < 5/4`; and both satisfy (i), since `5/6 < 5/2` and `0 < 5/2`. These two numbers are the `5/6` and the `5/4` quoted throughout this file. Note what the corollary is: a relation between a decay exponent and a dissipation exponent. It says nothing by itself about whether any solution of the model has front amplitude `c 2^(-b n)`.

**The dichotomy — CONJECTURE.** Setup, with the hypothesis marked. Call `A(n)` the amplitude of shell `n` at the moment `T_n` at which it is the active (energy-carrying) shell of the cascade, and **assume** — this is the regime hypothesis, and it is assumed, not derived — that the cascade advances one shell per turnover, so that `T_{n+1} - T_n ~ 1/(lam^n A(n))`, where `~` means "equal up to a factor bounded above and below by constants independent of `n`" (the coefficient of the transfer term out of shell `n` is `lam^(n+1)` and the partner amplitude is taken comparable to `A(n)`). Under that hypothesis:

Three facts, each a one-line computation.

1. **Finite escape time.** The cascade reaches `n = infinity` at the finite time `T* = T_0 + sum_n (T_{n+1} - T_n)` iff `sum_n 1/(lam^n A(n)) < infinity`; for a power-law `A` this is part (i) of the lemma, i.e. `b < 5/2`. Both regimes considered below satisfy it comfortably. *Withdrawn:* the earlier version of this item read "`sum_n 1/(lam^n A(n)) < infinity` iff `A(n)` decays slower than `lam^(-n)` up to summable corrections". That is not a theorem — the qualifier carries the content — and its "if" direction is false: `A(n) = lam^(-n) log(n+2)` decays strictly slower than `lam^(-n)` (the ratio tends to infinity) yet `sum_n 1/(lam^n A(n)) = sum_n 1/log(n+2)` diverges. Only the converse is elementary: if the sum converges then `lam^n A(n) -> infinity`. Part (i) of the lemma is what is used below.
2. **Dissipation is beaten at shell `n`** when the transfer rate exceeds the damping rate, `lam^n A(n) >> nu 2^(2 s n)`, with `>>` read precisely as "the ratio tends to `+infinity` as `n -> infinity`". For a power-law `A` this is part (ii) of the lemma: `b < 5/2 - 2 s`, i.e. `A(n) 2^((5/2 - 2s) n) -> infinity`. At `s = 1` the threshold exponent is `b < 1/2`: the front amplitude must decay **strictly slower than the scale-invariant profile of C2**.
3. **Energy bounds the front** (this one is exact, PROVED-HERE, from C1 with `nu >= 0`). `A(n)^2 <= sum_m a_m^2 = E(t) <= E_0`, so `A(n) <= sqrt(E_0)`: the best possible cascade in this class is one in which an order-one fraction of the total energy occupies the single active shell, i.e. `b = 0`.

Consequences (CONJECTURE, inherited through the regime hypothesis). Substituting the constant-flux profile `b = 5/6` of C5 into item 2 gives `s < 5/6`: the constant-flux cascade beats dissipation exactly below the threshold whose measured analogue is C8. Substituting the maximal profile `b = 0` (item 3) gives `s < 5/4`.

### C11. Why a one-mode-per-scale cascade cannot reach the front regime, and why adding modes in a chain does not help — **CONJECTURE**, with **COMPUTED** support

Every such chain has the exact energy identity of C1 (script part 5a verifies that the trilinear form vanishes identically in sympy with all `c_j` symbolic), so all of them are admissible carriers as far as the energy identity is concerned.

Heuristic obstruction (the reason the conjecture is stated, not proved). For a *complete* transfer, mode `j` must fill before it starts to drain, i.e. its outflow rate `c_{j+1} a_{j+1}` must be small compared with its inflow rate `c_j a_{j-1}` during filling — informally `c_{j+1} << c_j`. ### C12. What blocks porting the mechanism to true Navier-Stokes — **KNOWN** (survey of the obstructions), with the specific comparisons tagged

The mechanism of C10 needs a nonlinearity whose triad coefficients can be chosen: to build a gate one must be able to switch a particular interaction off while leaving another on. The true nonlinearity does not allow this, for four separate reasons, each of which is also the reason one of the transfer tests bites.

1. **The triad coefficients are fixed by geometry, not choosable.** For `B(u,v) = -P((u.grad)v)` on `T^3`, the interaction coefficient of the triad `k = p + q` is determined by the Fourier coefficients through `-i P_k (u_p . q) v_q`, with `P_k = I - k k^T/|k|^2` the Leray projector — a single fixed formula, with no free parameters. Tao's averaging (item 2.2) replaces `B` by an average of rotated and multiplier-modified copies of `B`, which changes those coefficients while preserving the energy identity `<B~(u,u),u> = 0`, the scaling, and every bilinear estimate; that freedom is exactly what makes the gadget constructible for `B~` and not for `B`. This is transfer test T1 in its sharpest form: any argument that would show that the mechanism of C10 fails for `B` must use something that averaging destroys.
2. **Transport structure and the vorticity equation.** The exact nonlinearity is a transport term plus a stretching term: `(d_t + u.grad) omega = (omega.grad) u + nu Laplacian omega`. Transport gives Lagrangian conservation laws (Kelvin circulation, helicity in the inviscid case), a maximum principle in two dimensions and in the swirl-free axisymmetric case (no-go items 2.8, 2.9), and the BKM criterion `int_0^{T*} ||omega(t)||_infinity dt = infinity` (item 2.7). A dyadic or averaged nonlinearity has none of this; in particular the dyadic model has no vorticity, no BKM criterion, and no notion of the direction of vorticity (Constantin-Fefferman). Transfer test T2 says a blowup mechanism that survives the 2D and swirl-free reductions is wrong, and the cascade of C10 has no way of even being restricted to them — it is not a mechanism *for* Navier-Stokes until it is realized by an actual velocity field.
3. **The pressure is nonlocal.** `p = sum_{i,j} R_i R_j (u_i u_j)` with `R_i` the Riesz transforms, so the projector `P` couples every mode to every other; one cannot localize a gadget in frequency space and expect it to stay decoupled from the rest of the flow, and one cannot add a "gate mode" without it interacting with everything through the pressure. This is also why the Burgers comparison in T2 has force: without pressure the equation is regular by the maximum principle, so the mechanism must use incompressibility, and incompressibility is precisely what makes the interactions unchoosable.
4. **The scaling budget is already saturated.** By C10 the maximal cascade in this class beats dissipation only for `s < 5/4`; at `s = 1` it needs the front amplitude not to decay. For real Navier-Stokes this is the statement that a blowup must keep an order-one fraction of the energy in the active scale at every stage of the cascade, which by `00_problem.md` 1.6 means the solution must stay of order one in a critical norm all the way down — consistent with, and no stronger than, the ESS constraint `lim ||u(t)||_{L^3} = infinity` of item 2.4 and Leray's lower bounds of item 2.5. In other words the cascade picture does not by itself contradict any known constraint; it also does not by itself produce a velocity field.

**The fluid computer.** Cardona, Miranda, Peralta-Salas and Presas, "Constructing Turing complete Euler flows in dimension 3", PNAS 118 (2021) [checked via WebSearch: authors, title, venue, and the statement that they build stationary Euler flows on a Riemannian 3-manifold that simulate a universal Turing machine, with undecidable trajectories], and Dyhr, Gonzalez-Prieto, Miranda and Peralta-Salas, "Turing complete Navier-Stokes steady states via cosymplectic geometry", arXiv:2507.07696 (2025), PNAS Nexus [checked via WebSearch: authors, title, arXiv id, venue, and the statement that universality holds on manifolds admitting a nonvanishing harmonic 1-form, so viscosity does not obstruct universality], show that fluid dynamics can carry universal computation. It is tempting to read this as "one can program a fluid to blow up". That inference fails, for a reason worth stating precisely: **the constructed flows are stationary.** A steady solution `u(x)` has `||u(t)||_{H^s} = ||u(0)||_{H^s}` for all `t`, so it never blows up; the computation is carried by the *trajectories of the fluid particles*, i.e. by the flow of a fixed vector field, not by the time evolution of the velocity field itself. The undecidability is about where a particle goes, not about whether the solution stays smooth. To convert Turing completeness into a blowup one would need a *non-stationary* computation whose steps are the transfers of C10, running at a geometrically accelerating clock rate, with the clock rate set by the local amplitude, and with each step's gadget occupying half the linear scale of the previous one — none of which the stationary constructions provide, and the accelerating clock is exactly the part that the fixed triad coefficients of point 1 obstruct. The argument rests on stationarity alone, which is airtight, and on nothing about the underlying manifold: the same group later constructed Turing-complete stationary Euler flows of Beltrami type in Euclidean space ("Computability and Beltrami fields in Euclidean space", arXiv:2111.03559 [checked via WebSearch: title only]), and the 2025 Navier-Stokes result needs only a nonvanishing harmonic 1-form, a condition the flat torus satisfies, so any claim that these constructions are excluded from the Clay class of `00_problem.md` 1.1-1.3 on geometric grounds would be [unverified] and is not made here. Tagging: the statements about the two papers are [checked via WebSearch] as indicated; the reading of what they do and do not imply for blowup is CONJECTURE (mine, not claimed by those authors).

## Breakpoint

This line stops at two places, and it is worth separating them because the second is much harder than the first.

**Breakpoint 1 (inside the ODE world).** C10 says a cascade beats the true dissipation exactly when its front amplitude `A(n)` does not decay faster than `2^(-n/2)`, and C11 says no chain of pairwise transfers achieves that, because the requirement "each transfer completes before the next begins" needs the chain coefficients to decrease along the chain while scale invariance forces them to increase by `lam` per scale. The exact step where this line stops: **a gate has to be built out of a genuine three-mode interaction, and I did not build one.** Concretely, one needs modes `(x, y, g)` with an energy-conserving quadratic law (`x' = a y g`, `y' = b x g`, `g' = c x y`, `a + b + c = 0`) arranged so that the `x -> y` transfer is off until `g` has grown, with the growth of `g` timed to the completion of the previous scale's transfer, and the whole triple reproducing itself at the next scale under the scaling map of C2 with time contracted by `1/4`. Tao's construction does this with several modes per scale (a pump, a rotor and a transfer gadget) and a careful choice of the amplification factors. C11 is therefore CONJECTURE, not a theorem: I have a mechanism for why chains fail and numerics showing six of them failing in the same way, but no proof that no chain works, and no explicit gadget that does.

**Breakpoint 2 (the port to the true equation, and the real one).** Even a completed gadget is an ODE system, not a fluid. To port it one must exhibit divergence-free vector fields `psi_{n,i}` on `T^3`, with `psi_{n,i}` localized at frequency `~2^n`, such that the *actual* Euler trilinear coefficients `<B(psi_{n,i}, psi_{n,j}), psi_{n',k}>` — with `B(u,v) = -P((u.grad)v)` and `P` the Leray projector — equal the gadget's coefficients up to errors the construction can absorb. **This is where the line stops for good: those coefficients are not free.** For the triad `k = p + q` on the torus they are fixed by `-i P_k(u_p . q) v_q` with `P_k = I - k k^T/|k|^2`; there is no parameter to tune, the projector couples every mode to every other (the pressure is nonlocal), and a gate needs a specific interaction to be *absent*, which the geometry does not permit. Tao's resolution is not to port the gadget but to change the nonlinearity: `B~`, an average of rotated and multiplier-modified copies of `B`, has choosable coefficients while keeping the energy identity, the scaling and every bilinear estimate (no-go item 2.2). So the honest statement of the breakpoint is: **this line reproduces the reason the averaged equation blows up and the reason the same construction cannot be written down for the exact equation, and it does not narrow the gap between them by one line.** Closing that gap in the blowup direction requires a genuinely new idea about how to realize a delayed, amplitude-amplifying transfer with the coefficients that the Leray projector actually gives; closing it in the regularity direction requires (by transfer test T1) an argument that uses vorticity transport, the Lagrangian structure, the Biot-Savart geometry, the pressure formula or a maximum principle, none of which the models here possess at all.

A third, smaller gap is recorded honestly in C6: the shape of the inviscid profile at the escape time is not resolved by these runs, so whether `H^1` is finite at the model's inviscid blowup time is left open here.

## What would be needed next

- **Build the gate.** An explicit energy-conserving triad with a delayed switch, verified symbolically, chained so that the scaling map of C2 carries stage `n` to stage `n+1` with time contracted by `1/4`, and shown numerically to have front amplitude `A(n)` bounded below (slope `0`, not `-5/6`) and transfer times shrinking like `4^(-n)`. C10 says this must then blow up for every `s < 5/4` and stop at `5/4`; that prediction is the acceptance test for the construction, and it would be a sharp check of the whole picture.
- **Turn C11 into a theorem.** Prove that for every chain model with positive coefficients and scale invariance, the front amplitude obeys `limsup 2^(5n/6) A(n) < infinity`, i.e. the constant-flux profile is an upper barrier. This is presumably close to the mechanism of the Barbato-Morandin-Romito positivity proof and would explain, in one inequality, why one mode per scale can never suffice.
- **Resolve C6.** Decide whether `H^1` is finite at the inviscid escape time by integrating the model in the self-similar variables `tau = T* - t`, `n' = n - log_lam(1/tau)`, where the front is stationary and the truncation is not the limiting factor.
- **Attack the port head on.** Compute, for a concrete family of divergence-free wave packets on `T^3` at frequencies `2^n`, the actual trilinear coefficients `<B(psi_a, psi_b), psi_c>` and ask how close a gate one can build from them — i.e. how small the unwanted interactions can be made relative to the wanted ones. A quantitative answer (even a negative one, of the form "the unwanted coefficients are at least a fixed fraction of the wanted ones") would convert Breakpoint 2 from a qualitative obstruction into a measured one, and that is the most useful next object this line points at.

cd research/navier-stokes
python3 line_c_cascade.py

Requires `numpy`, `scipy`, `sympy`. Deterministic (no random numbers anywhere); total wall time about 3 minutes on 4 CPUs; all output is printed to stdout and no files are written.
