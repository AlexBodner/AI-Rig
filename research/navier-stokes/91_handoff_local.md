# 91 — Handoff to a session with library access

This attempt was made in a sandboxed cloud session whose egress policy blocks the entire mathematical literature. That single restriction is the binding constraint on the whole project, and it is the reason several claims below carry a weaker status than the underlying mathematics may deserve. This file lists, in priority order, the work that a session with ordinary network access can do and this one could not. It is written for whoever picks the project up, human or agent.

## What was blocked

Confirmed unreachable by direct request from the session: `arxiv.org`, `export.arxiv.org`, `doi.org`, `pnas.org`, `link.springer.com`, `sciencedirect.com`, `jstor.org`, `scholar.google.com`, `ncbi.nlm.nih.gov`, `europepmc.org`, `api.semanticscholar.org`, `api.openalex.org`, `api.crossref.org`, `core.ac.uk`, `zenodo.org`, `hal.science`, `terrytao.wordpress.com`, `mathstodon.xyz`, `en.wikipedia.org`, `x.com`. A web search tool returning titles, venues and short snippets was the only external channel. Consequently **no full text of any cited paper was read anywhere in this project**, and the citation tags mean only what section 0 of `00_problem.md` says they mean.

## Priority 2 — read the two primary sources this project is about

Tao's Mathstodon thread of 2026-09-03 (`https://mathstodon.xyz/@tao/117207849921390904`) is the motivation for the whole write-up and was reconstructed only from search snippets of its first two parts; the remaining parts were never read. Tao's blog post of 2014-02-04 announcing the averaged Navier-Stokes construction was identified by the user as the approach they had in mind and was likewise confirmed only through an abstract snippet. Read both and correct anything in `README.md` or in item 2.2 of `00_problem.md` that misrepresents them.

## Priority 3 — extend the machine-checked layer

`lean/Certificates.lean` checks 63 theorems with core Lean 4.15 and no axioms, but it covers only finite arithmetic because mathlib could not be downloaded. With mathlib available, the following are worth attempting in increasing order of difficulty: the scaling arithmetic of section 1.6 of `00_problem.md` and the exponent classification of `line_b_selfsimilar.md`, which are real-number algebra; the amplitude-scaling lemma A1, which needs Fréchet derivatives and a local existence statement as a hypothesis rather than a theorem; and the symbolic profile identity of line B, currently verified only by computer algebra. Do not attempt the Liouville theorems: they need a substantial PDE development that does not exist in mathlib.

## Priority 4 — computations this session could not afford

The session had four cores and no GPU, so no three-dimensional direct numerical simulation was attempted and none of the numerical claims involve one. Worth running with real compute: a resolution study of the enstrophy-maximizing fields of `line_a_lyapunov.py` against the published extreme-vortex-state literature; a finer and better-converged scan of the dyadic dissipation threshold in `line_c_cascade.py`, whose current estimator is calibrated against a remembered proved value; and an interval-arithmetic certificate for the global-maximality claim in A3.3 of `line_a_lyapunov.md`, which is currently recorded as conditional and would need grids above roughly 200 points per dimension.

## How to continue

Everything is on the branch `claude/mathstodon-problem-qwmcq7`. Clone the repository, check that branch out, and read `README.md` first, then `00_problem.md` section 0, before trusting any citation in the project. The scripts need only numpy, scipy, sympy and mpmath, and run in 53, 17, 149, 52 and 190 seconds respectively for lines A to E. The Lean file needs the toolchain named in `lean/README.md` and checks in about 10 seconds.
